# 🚗 AutoBro — Сервис подбора автомобиля

> *AutoBro* — твой надёжный советчик в мире автомобилей.  
> Просто расскажи, что ищешь, а он подберёт лучший вариант.

---

## 📋 О проекте

**AutoBro** — это консольное приложение на Java, которое помогает пользователям подобрать автомобиль на основе их предпочтений.  
Пользователь отвечает на несколько вопросов (бюджет, тип кузова, расход топлива и т.д.), а система формирует список подходящих вариантов из встроенной базы данных.

Проект выполнен в рамках курсовой работы и демонстрирует применение принципов **SOLID**, **трехуровневой архитектуры** и работы с базами данных на Java.

---

## 🎯 Основная функциональность

### 👤 Для пользователя:
- **Ввод критериев подбора:**
  - Бюджет (от/до)
  - Тип кузова (седан, универсал, кроссовер, хэтчбек)
  - Тип привода (передний, задний, полный)
  - Тип трансмиссии (механика, автомат, робот, вариатор)
  - Максимальный расход топлива
  - Возраст автомобиля

- **Результат подбора:**
  - Вывод топ-5 автомобилей в виде таблицы
  - Сохранение результата в файл `report.txt`

### 🔧 Для администратора:
- Добавление новых автомобилей в базу
- Удаление автомобилей из базы
- Режим доступа по паролю

## ✅ Требования к реализации

- **Обработка ошибок:** Приложение не должно завершаться аварийно при некорректном вводе.
- **Стиль кода:** Соблюдение Java Code Conventions.
- **Тестирование:** Ключевые методы фильтрации покрыты юнит-тестами.
- **Документация:** Код содержит Javadoc комментарии к публичным методам.
